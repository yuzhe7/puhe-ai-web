### 1.4 数据设计原则与免责声明

1. **不声称穷尽**：全国本科专业共 845 种，本目录只收录 54 个「能与产业岗位 JD 做语义对齐」的热门 / 战略急需专业；艺术、体育、纯理论方向因缺乏可对齐的技能语料暂不纳入，目录页保留扩展接口。
2. **演示数据声明**：所有课程、学时、学分、在招数、薪资、热度、专业人数均为**教学演示抽样数据，非真实统计**，已在 `/api/majors` 的 `disclaimer`、目录页页脚、README 与技术文档中三处显式声明；答辩时应主动说明，避免被质疑数据造假。
3. **引用完整性优先**：新增专业的每门课程都在课程表中登记，每个课程的知识点都在知识点表中登记，每个岗位的技能都在技能表中登记；由 `scripts/audit-data.cjs` 与运行时 `dataIntegrityReport()` 双重校验。
4. **可扩展**：新增专业只需在 `src/lib/hot-majors.ts` 追加 `majorMeta` 与 `M(...)`，无需改动图谱、沙盘、路径、诊断任何一行算法代码。

## 二、漏洞审计

### 2.1 审计范围与方法

覆盖 11 个 API Route、10 个页面、8 个核心算法模块、主题/图表组件、构建配置与依赖完整性。方法为：静态代码走查 → 数据引用离线审计 → 越界 / 畸形输入模糊测试 → 限流与安全响应头实测 → SSE 流式与工具链联调 → 构建产物体积检查。

## 四、结论

1. **功能目标达成**：专业从 12 扩到 54，覆盖教育部 2025 新增、绿牌、热度榜、布点增长、预警等 6 类口径，9 大分类，所有图谱 / 诊断 / 沙盘 / 路径 / 报告链路在新专业上均可正常计算，新增 `/majors` 目录页把「来源可追溯 + 数据完整性」直接做成可演示能力。
2. **安全目标达成**：从「能跑」推进到「能抗畸形输入、能抗刷、能抗 RAG 投毒、不泄漏内部信息」，且这些加固本身可转化为赛道「AI 安全与可控性 4%」与「前端工程 / 体验」的举证材料。
3. **诚实边界**：系统仍是**教学演示原型**，不是生产级产教融合平台。语义对齐精度、数据真实性、共享存储与鉴权是最大的三项残余风险，报告与答辩中应主动披露而非回避——评委对「清楚知道自己局限」的作品评价通常更高。
