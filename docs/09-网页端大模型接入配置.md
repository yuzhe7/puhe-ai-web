# 网页端大模型接入配置（v5）

> 解决的问题：v4 的 LLM 接入层已完备，但只能通过 `.env.local` 配置、改完必须重启服务。
> v5 新增「模型接入」页面，让参赛者 / 评审**在网页里直接填密钥、测连通性并一键启用**，
> 配置即时生效，无需改环境变量、无需重启。

---

## 一、先澄清：项目里没有自训模型

所有诊断数值（专业相似度、能力偏差、知识点缺口、沙盘匹配度、路径最短距离）都由
`lib/graph.ts` / `simulator.ts` / `pathway.ts` 的**确定性算法**产出。
大模型只负责三件事：语言组织、意图理解、Function Calling 工具编排。
所以「接入大模型 API」= 给已有 Agent 链路换一个可插拔的语言引擎，**不改动任何业务算法**。

启用后受影响的功能：AI Copilot 的流式回答、Deep Research 的综合阶段、报告生成的表述层。
未启用时自动走本地确定性引擎，**全部功能仍可离线完整演示，零 token 消耗**。

## 二、新增能力

| 能力 | 位置 | 说明 |
|---|---|---|
| 运行时配置层 | `src/lib/ai/runtime-config.ts` | `globalThis` 内存态配置，跨 chunk 共享；校验、SSRF 防护、脱敏、来源判定 |
| 配置 API | `GET/POST/DELETE /api/models` | 查看当前生效配置 / 保存启用 / 清除回落 |
| 连通性自检 | `POST /api/models/test` | 发一条极短非流式请求，返回延迟与模型回复片段；错误按 401/404/429/超时分类，不回传上游原文 |
| 配置页面 | `/models` | 服务商预设卡片、密钥表单、显隐切换、测试连接、保存并启用、恢复本地引擎、安全说明 |
| 状态联动 | `/api/status` + AppShell | 新增 `configSource`；保存后侧栏「AI 引擎」徽标即时刷新，显示「魔搭 · 模型名 · 网页配置」 |
| 全站入口 | 首页 Hero、侧栏导航、`⌘K` 命令面板 | 关键词 `model / llm / api key / token / 魔搭 / 接入` 均可搜到 |

支持 6 类来源：**魔搭 ModelScope API-Inference、DeepSeek、智谱 AI、阿里云百炼、OpenAI、自定义 OpenAI 兼容端点**（含本地 Ollama / vLLM 网关）。

### 2.1 可以接入哪些模型

页面左侧「可选模型」卡片会**随所选服务商切换**，点击即填入对应输入框；下面是完整清单（模型会上下线，以厂商控制台与「测试连接」为准）。

| 服务商 | 文本 / 对话模型（支持 Copilot） | 视觉模型（图片 JD 抽取） | 备注 |
|---|---|---|---|
| **魔搭 ModelScope** | `Qwen/Qwen3-Coder-30B-A3B-Instruct`（默认）、`Qwen/Qwen3-235B-A22B-Instruct-2507`、`deepseek-ai/DeepSeek-V3.2` | `Qwen/Qwen2.5-VL-72B-Instruct`、`Qwen/Qwen3-VL-235B-A22B-Instruct` | 免费推理额度、动态限流；需绑定阿里云账号并实名；社区实测前三个支持 Function Calling |
| **阿里云百炼 / 通义千问** | `qwen-plus`（预设默认）、`qwen-max`、`qwen-turbo`、`qwen-long`、`deepseek-v3` | `qwen-vl-max`、`qwen-vl-plus`（另有 `qwen3-vl-plus` 等） | 按 token 计费；`dashscope.aliyuncs.com/compatible-mode/v1` |
| **DeepSeek 官方** | `deepseek-chat`（V3，支持工具调用）、`deepseek-reasoner`（R1） | 无，视觉 ID 请留空 | **`deepseek-reasoner` 不支持 Function Calling**，Copilot 会降级到本地引擎 |
| **智谱 AI** | `glm-4-flash`（免费档）、`glm-4-air`、`glm-4-plus` | 以控制台当前在售 VL 模型为准 | 免费档并发较低 |
| **OpenAI** | `gpt-4o-mini`、`gpt-4o` | `gpt-4o` | 需海外网络与付费账户 |
| **自定义兼容端点** | 任意实现 `/chat/completions` 的模型，如 Ollama `qwen2.5:7b`、vLLM `Qwen/Qwen2.5-7B-Instruct`、硅基流动 / 豆包 / Moonshot / Gemini OpenAI 兼容网关 | 取决于网关 | 本地小模型多数不支持 `tools`，会自动降级 |

**三条硬约束**：

1. **必须支持 Function Calling**：AI Copilot 会传 `tools` 参数并做多轮工具循环。不支持工具调用的模型（如 DeepSeek-R1、多数本地小模型）会触发失败降级，功能仍在但看不到工具轨迹。
2. **视觉模型必须支持 `image_url`**：只有填写「视觉模型 ID」才启用图片 JD 抽取；文本模型填进去会报错，留空即关闭多模态。
3. **模型 ID 命名规则不能混用**：魔搭 / 自建网关用「命名空间/仓库名」（`Qwen/xxx`），百炼 / DeepSeek / 智谱 / OpenAI 用短名（`qwen-plus`、`deepseek-chat`）。**把 `Qwen/Qwen2.5-VL-72B-Instruct` 填到百炼端点会直接 404** —— 这是切换服务商时最常见的坑，配置页已加命名空间检测与切换自动清理。

> `/models` 页面可随时点「测试连接」验证任意模型 ID：它会对 `/chat/completions` 发一条极短请求，返回延迟与模型回复，失败按 401/404/429/超时分类提示。

## 三、操作步骤（最简路径）

1. 打开 `/models`（或首页「接入大模型 API」）
2. 在左侧点「魔搭 ModelScope · API-Inference」预设，自动填入
   `https://api-inference.modelscope.cn/v1` 与 `Qwen/Qwen3-Coder-30B-A3B-Instruct`
3. 粘贴 SDK Token（<https://modelscope.cn/my/myaccesstoken>，形如 `ms-xxxx`）
   - 首次使用需**绑定阿里云账号并完成实名认证**
4. 点「测试连接」→ 通过后显示延迟与模型回复（`OK`）
5. 点「保存并启用」→ 侧栏徽标变为 `魔搭 · Qwen3-Coder… · 网页配置`
6. 进 `/copilot` 提问，可看到真实模型的流式输出与工具执行轨迹

**换模型不重贴密钥**：`apiKey` 留空时后端沿用同一进程内已保存的密钥，只更新模型 ID / Base URL。
**恢复离线**：点「恢复本地引擎」或调用 `DELETE /api/models`。

## 四、密钥与合规设计（对应赛道「密钥不得入库」）

1. 密钥**只存在于当前 Node 进程内存**（`globalThis`），不写磁盘、不写 localStorage、不进 Git、不进日志；
2. 所有响应只返回 `maskToken()` 的脱敏值（前 3 后 2），**任何接口都不回传密钥本体**；
3. 服务 / 容器重启后自动清空，回落到 `.env.local` 或本地引擎；
4. Base URL 校验：必须 `https`，仅 `localhost / 127.0.0.1 / ::1` 允许 `http`；禁止 URL 内嵌账号密码、查询参数与片段，阻断 SSRF 通道；
5. 输入校验：密钥 ≤256 字符、拒绝中文 / 空格 / 控制字符 / 模板占位符；模型 ID 白名单字符 `[A-Za-z0-9._/:@-]` 且 ≤128 字符；请求体 ≤4 KB；
6. 限流：配置写操作 10 次/分钟、连通性测试 5 次/分钟（测试会消耗少量 token）；
7. 错误响应统一泛化（`serverError` / `classify`），上游地址、密钥片段、堆栈不外泄。

> **生产 / 创空间部署仍推荐 `.env.local` 或平台 Secrets**：网页配置是单进程内存态，
> 多副本部署不共享，且重启即失效。演示与现场调试用网页配置最方便。

## 五、配置优先级

```
DEMO_MODE=true  → 强制本地引擎（网页配置不生效）
      ↓
网页运行时配置（/api/models 保存，source=runtime）
      ↓
环境变量 .env.local / 平台 Secrets（source=env）
      ↓
本地确定性引擎（source=none，完整功能、零 token）
```

`llm.ts` 的 `getLlmConfig()` / `getVisionConfig()` 都先读运行时配置，再回落到原有环境变量逻辑；
`chat / research / status / vision` 全部自动跟随，无需逐个改。

## 六、接口速查

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/models` | 返回当前配置（脱敏）、状态、服务商预设、魔搭候选模型、安全说明 |
| POST | `/api/models` | 校验并保存配置，返回生效状态 |
| DELETE | `/api/models` | 清除网页配置，回落到 env 或本地引擎 |
| POST | `/api/models/test` | `{ useCurrent: true }` 测当前配置，或直接带表单字段测未保存的配置 |
| GET | `/api/status` | 新增 `configSource`、`runtime-model-config` 能力标记与新端点清单 |

连通性测试返回示例：

```json
{ "ok": true, "latencyMs": 842, "model": "Qwen/Qwen3-Coder-30B-A3B-Instruct", "reply": "OK" }
```

失败时只给分类文案，例如 `密钥无效，或该密钥无权访问此模型` / `触发上游限流（免费额度常见），稍后重试即可`。

## 八、已知边界

- 运行时配置为**进程内存态**：多实例 / Serverless 多副本下不共享；重启失效（设计如此）。
- 连通性测试会发起一次真实请求，**消耗极少量 token**；免费额度紧张时可跳过直接保存。
- 自定义端点仅保证 OpenAI `/chat/completions` 协议；若网关不支持 `tools`，Function Calling 会失败并触发本地引擎降级。
- 视觉模型需显式填写 ID 才会启用，避免把不支持 `image_url` 的文本模型误配上去。
