## 三、作品简介（200 字版）

谱合产教是一套面向高校专业建设的产教融合智能诊断平台。平台以知识图谱为数据底座，将高校侧的专业、培养目标、课程、知识点，与产业侧的岗位类别、能力要求、技能点纳入同一本体，在微观粒度上完成对齐与量化分析，回答三个问题：哪些专业重复建设、培养目标偏离产业多少、哪些知识点应当加强或精简。

平台覆盖 62 个专业、109 门课程、334 个知识点、38 类岗位，基于 28,640 条岗位需求样本。核心特点是所有数值均由本地确定性算法产出，可逐层溯源并独立复算，大模型仅负责语言组织，从机制上排除编造数字的可能。

## 四、作品简介（500 字版）

谱合产教是一套面向高校专业建设的产教融合智能诊断平台，解决专业设置与课程体系长期依赖经验判断、缺乏可量化证据链的问题。

平台以知识图谱为数据底座，构建双侧三层本体：高校侧由专业、培养目标、知识点三级构成，产业侧由岗位类别、能力要求、技能点三级构成，两侧通过战略适配、包含分解、语义匹配三类关系相连。同一套本体同时支撑三维诊断、改革沙盘与能力路径三个模块，各模块无需维护独立数据副本。

在此基础上，平台提供三层递进式诊断：宏观层以课程相似度、知识点重叠率与图拓扑余弦加权计算专业同质化程度；中观层以 12 项工程教育认证毕业要求构建统一能力词表，计算校内覆盖度与产业需求度的偏差；微观层对每个知识点完成跨域语义对齐，输出应加强、应新增、可精简三类判定。

诊断结论可进一步转化为决策：培养方案改革沙盘支持调整学时与增删产业模块，五个维度指标实时重算，并可在学时预算约束下由算法给出寻优方案；岗位能力路径以图算法求解最短补强链，输出面向学生的分学期学习计划。

平台的技术特点是端侧确定性与可验证性。全部数值由本地算法产出，任一分数可展开查看计算公式、中间量与结果，并附一次独立复算；大模型仅负责语言组织，从机制上排除编造数字的可能。由此实现零密钥可运行、断网可演示、结果可复现。

系统包含 14 个功能页面、18 个后端接口与 10 个 MCP 工具，已部署至公网供在线访问，并建立三层测试体系：122 项脚本断言、19 项运行时自检、28 条 Agent 评测用例。

## 五、项目亮点（分条填写）

1. 分数可核查：任一分数可展开计算公式与中间量，并由独立路径复算比对，不一致即标红。
2. 三层递进诊断：宏观专业同质化、中观培养目标偏差、微观知识点缺口串成一条分析链，结论可落到具体知识点的学时调整。
3. 诊断可转化为决策：改革沙盘支持学时与产业模块调整，五维指标实时重算并可自动寻优。
4. 交付物可用：导出 18 列课程矩阵 CSV，UTF-8 BOM 编码，可直接导入教务系统。
5. 零密钥可运行：数值计算全部在端侧完成，断网可演示、结果可复现。

## 六、AI 技术要点（用于「AI 技术说明」类字段）

- 多智能体编排：检索、规划、对齐、诊断、报告五个智能体构成流水线，工具调用以 SSE 增量下发，可观测。
- 检索增强：端侧 TF-IDF 稀疏检索配合查询扩展与标题加权，不依赖外部向量数据库。
- 协议复用：同一套工具注册表同时面向大模型 Function Calling 与外部 Agent 的 MCP 接口。
- 安全可控：七条系统硬约束、输入侧注入拦截、输出侧数值溯源校验、PII 脱敏，异常自动降级本地引擎。
- 质量可测：28 条固定用例、四项指标，含自研的「自检漏报」元评测，用于评估校验逻辑本身是否失效。

## 十、常见追问的备答

**问：数据是否真实？**
答：演示数据由团队自建，不含真实学生个人信息。专业目录分两层口径：12 个为试点校抽样专业，另 50 个为全国学科目录观察池，页面以来源标签区分。系统内置数据审计脚本，检查引用闭合与口径一致。

**问：AI 在其中起什么作用？**
答：AI 承担语言组织与工具编排，不产生任何数值。所有数值来自本地确定性算法，可溯源、可复算，这是平台与同类工具的主要区别。

**问：与已有产品有何差异？**
答：多数同类工具提供结论但无法验证结论来源。本平台把「可验证」做成了产品能力：分数可展开计算链、可独立复算，系统自检与 Agent 评测结果对用户可见。

**问：能否部署到学校？**
答：可以。提供 Dockerfile，单容器部署，监听 7860 端口；无密钥环境下自动使用本地引擎，功能不受影响。
