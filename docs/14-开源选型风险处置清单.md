## 5. 有意不做的处置（避免制造新风险）

1. **不安装 B1 三项依赖**：装 Zod / Playwright 会改 `package.json` 与校验层，历史上本项目出现过 `package-lock` 残缺、SWC/unpdf 大文件截断、`.next/trace` 锁等构建问题；留作你确认后的独立批次，便于出问题时精确回退。
2. **不引入任何 A/C 类平台代码**：不把 GPL 数据、禁 SaaS 平台、Python 重栈、常驻数据库打进上传包；守卫已把这条变成 FAIL 级检查。
3. **不改 `Dockerfile` 里整包复制 `node_modules` 的做法**：注释已说明是为保证 `unpdf` / `mammoth` 等动态 import 依赖可解析；虽然比官方三件套略重，但贸然删除会破坏运行时，风险大于收益。
4. **不做真实 Docker 构建**：本机无 Docker，静态校验 + 部署前命令清单是本次可交付的最强验证。
5. **不自动「修正」调研文档里的旧路径字符串**：它们是纠错说明，删掉反而丢失调研证据。
